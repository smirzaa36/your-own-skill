# Your Own Skill

## Prompt 1

Create one portable agent skill named `resume-roast` that compares a supplied resume with a supplied job post and gives blunt, specific fixes. Keep the skill focused on this task. It must start correctly in a fresh session, work from provided material without inventing facts, and handle three different fictional resume/job-post pairs. First complete the same review once without using the skill; then use the skill on that exact same pair and document what improved. Include the skill instructions, the three sample inputs and their reviews, and the before/after comparison. Keep all files in this project folder, use fictional harmless sample data, and do not install anything globally. Validate the skill structure and verify that all three sample pairs have corresponding reviews.
